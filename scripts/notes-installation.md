### Installer

| Appareil | Fichier |
|---|---|
| Mac | `Alpagamp-X.Y.Z.dmg` : l'ouvrir, glisser Alpagamp dans Applications, puis **clic droit → Ouvrir** la première fois (appli non signée). |
| Windows 10/11 | `Alpagamp-X.Y.Z-windows-x64.zip` : extraire, lancer `alpagamp.exe`, puis **Informations complémentaires → Exécuter quand même**. |
| Android 8+ | `Alpagamp-X.Y.Z.apk` : l'ouvrir sur le téléphone, autoriser l'installation, puis l'accès à la musique. |

Tout est expliqué pas à pas dans le [README](https://github.com/Guiwald/alpagamp#installer).

### Install

| Device | File |
|---|---|
| Mac | `Alpagamp-X.Y.Z.dmg`: open it, drag Alpagamp to Applications, then **right-click → Open** the first time (the app isn't signed). |
| Windows 10/11 | `Alpagamp-X.Y.Z-windows-x64.zip`: extract it, run `alpagamp.exe`, then **More info → Run anyway**. |
| Android 8+ | `Alpagamp-X.Y.Z.apk`: open it on the phone, allow the installation, then music access. |

Step-by-step instructions are in the [README](https://github.com/Guiwald/alpagamp#english).
