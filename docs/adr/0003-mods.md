# ADR 0003 — Les mods : skins classiques, MilkDrop, plugins WASM ; AVS plus tard

- Statut : acceptée (13/10/2026)

## Contexte

Les plugins de Winamp (`in_`, `out_`, `vis_`, `dsp_`, `gen_`…) sont des DLL Win32 x86 : impossibles à charger sur
macOS, Android, iOS ou ARM, et sur Windows 64 bits seulement via un processus-pont 32 bits. Ce qui se porte, ce
sont les formats de données : skins `.wsz`, presets MilkDrop `.milk`, presets AVS `.avs`, presets d'EQ `.eqf`.
Les skins modernes `.wal` exigent une machine virtuelle MAKI (~65 classes non documentées).

## Décision

v1 :
1. **Skins classiques `.wsz`**, rendu complet et fidèle (y compris `region.txt`, `viscolor.txt`, `pledit.txt`,
   curseurs).
2. **Presets MilkDrop `.milk`** (fenêtre et plein écran).
3. **Un système de plugins à nous, en WebAssembly** (bac à sable, identique sur toutes les plateformes) :
   visualisation, effet audio (DSP), usage général. Livré avec 2 ou 3 plugins d'exemple.

Plus tard (v2) : **presets AVS**.

Jamais : DLL Winamp d'origine, skins modernes `.wal`.

## Conséquences

- Les presets et skins tiers ne sont pas embarqués dans le dépôt (voir ADR 0008).
- L'API de plugins doit être stable et versionnée (elle fait partie de « l'API publique » au sens de la
  convention de versions).
