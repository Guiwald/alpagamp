# ADR 0013 — Plugins d'exemple livrés avec l'API

- Statut : acceptée (13/10/2026)

## Décision

Un plugin WebAssembly d'exemple par catégorie, livrés avec la v1 et servant de modèles :

| Catégorie | Plugin | Ce qu'il fait |
|---|---|---|
| Visualisation | **Barres plein écran** | gros analyseur de spectre rétro, couleurs du skin |
| DSP | **Enhancer** | élargisseur stéréo + renfort de basses, à la DFX |
| Général | **Minuterie de sommeil** | fondu puis arrêt au bout de N minutes |
