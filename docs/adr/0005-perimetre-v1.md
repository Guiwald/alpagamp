# ADR 0005 — Périmètre de la v1

- Statut : acceptée (13/10/2026)

## Décision

La v1 reprend les fonctions de Winamp 2.9, plus quelques apports de la 5 :

- les trois fenêtres (principale, égaliseur, playlist), mode bandeau (windowshade), double taille, aimantation,
  toujours au premier plan ;
- le visualiseur intégré (analyseur, oscilloscope, toutes ses options) ;
- l'égaliseur 10 bandes, préampli, presets, fichiers `.eqf`, chargement automatique par morceau ;
- la playlist avec tous ses menus, M3U/M3U8/PLS, « Jump to file », temps total ;
- la radio Internet (SHOUTcast/ICY) ;
- les raccourcis clavier ;
- les infos de fichier (lecture seule) ;
- gapless, fondu enchaîné, ReplayGain, signets ;
- Spotify (ADR 0002) et les mods (ADR 0003).

Hors v1 :
- **Media Library** : gardée sous le coude, candidate pour la mise à jour suivante ;
- **AVS** : v2 (ADR 0003) ;
- vidéo, CD (lecture, extraction, gravure), minibrowser, podcasts, baladeurs, édition des tags.

Une petite fenêtre « bibliothèque » sert à choisir la musique Spotify (détails : ADR à venir).
